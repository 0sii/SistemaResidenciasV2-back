# Manual de usuario final
## Sistema de Vinculación de Proyectos

## 1. Introducción

Este sistema está diseñado para apoyar la gestión de proyectos de residencia o vinculación, desde la propuesta inicial hasta la entrega final. Permite a estudiantes, docentes, administradores y personal encargado del proceso revisar, aprobar, documentar y dar seguimiento a cada proyecto.

El sistema ayuda a:
- Iniciar sesión de forma segura.
- Crear y consultar proyectos.
- Asignar estudiantes, docentes y empresas.
- Revisar el estado de cada proyecto.
- Cargar documentos y entregables.
- Recuperar la contraseña en caso de olvido.
- Mantener un historial formal de la aceptación del anteproyecto.

## 2. ¿Quiénes pueden usar el sistema?

Los usuarios principales son:
- Estudiantes
- Docentes
- Asesores
- Administradores
- Personal académico o administrativo
- Empresas vinculadas a los proyectos

Cada usuario puede ver o modificar únicamente la información que le corresponde según su rol y permisos.

## 3. Requisitos para utilizar el sistema

Antes de entrar al sistema, asegúrate de tener:
- Un navegador web actualizado
- Conexión a internet
- Credenciales válidas de acceso
- Un correo institucional o válido para registro y recuperación de contraseña

## 4. Acceso al sistema

### 4.1 Inicio de sesión
1. Abre la página del sistema.
2. Escribe tu correo electrónico registrado.
3. Escribe tu contraseña.
4. Haz clic en "Iniciar sesión".
5. Si las credenciales son correctas, se abrirá la pantalla principal del sistema.

### 4.2 Recuperación de contraseña
Si olvidaste tu contraseña:
1. En la pantalla de inicio, selecciona la opción "Recuperar contraseña".
2. Ingresa tu correo electrónico o institucional.
3. El sistema enviará un código de verificación a ese correo.
4. Escribe el código recibido.
5. Crea una nueva contraseña.
6. Confirma la nueva contraseña y guarda los cambios.

> Importante: usa un correo válido y revisa también la bandeja de spam o correo no deseado.

## 5. Estructura principal del sistema

La pantalla principal puede incluir secciones como:
- Proyectos
- Usuarios
- Empresas
- Estudiantes
- Docentes
- Documentos
- Entregables
- Estados y revisiones

La apariencia puede variar según el rol asignado al usuario, pero la lógica general es la misma.

## 6. ¿Qué es un proyecto?

Un proyecto es la propuesta o iniciativa que se desarrolla dentro del programa de vinculación o residencia. Puede estar asociado a:
- Una empresa
- Un docente o asesor
- Un estudiante o equipo de estudiantes
- Un periodo académico
- Una especialidad o modalidad

Cada proyecto tiene información básica como:
- Título
- Descripción
- Objetivo
- Modalidad
- Empresa
- Periodo académico
- Estado actual

## 7. Cómo crear un proyecto

1. Inicia sesión en el sistema.
2. Accede a la sección "Proyectos".
3. Selecciona la opción "Nuevo proyecto" o "Crear proyecto".
4. Llena los siguientes campos:
   - Título del proyecto
   - Descripción general
   - Objetivo del proyecto
   - Modalidad
   - Periodo académico
   - Empresa asociada (si aplica)
   - Datos del estudiante o equipo responsable
5. Revisa que toda la información esté correcta.
6. Guarda el proyecto.
7. El sistema lo registrará con un estado inicial correspondiente.

> Si alguno de los campos es obligatorio y no lo llenas, el sistema puede rechazarte la operación o pedirte que completes la información faltante.

## 8. Estados del proyecto

Durante el ciclo del proyecto, este puede cambiar de estado. Algunos de los estados más comunes son:

- Publicado
- En espera de asignación de revisor
- En espera de revisión del anteproyecto
- En espera de asignación de asesor
- En curso
- Prórroga
- Cancelado

### ¿Qué significa cada estado?

#### Publicado
El proyecto ya fue registrado y está disponible para revisión o seguimiento.

#### En espera de asignación de revisor
El proyecto requiere que se asigne una persona para revisar la propuesta o el anteproyecto.

#### En espera de revisión del anteproyecto
La propuesta fue enviada y espera la evaluación del comité o del docente responsable.

#### En espera de asignación de asesor
El proyecto ya pasó una primera revisión, y ahora necesita un asesor interno para continuar.

#### En curso
El proyecto ya está activo y se está desarrollando en tiempo real.

#### Prórroga
Se otorgó más tiempo para concluir el proyecto o algún entregable.

#### Cancelado
El proyecto fue cancelado por alguna razón específica y no continuará.

## 9. Anteproyecto y aceptación formal

La aceptación del anteproyecto es una fecha importante dentro del proceso. El sistema guarda esta información para registrar cuándo el asesor o responsable interno aprobó formalmente la propuesta.

Esto ayuda a:
- Mantener un historial claro del proceso
- Evitar confusiones sobre la fecha real de aprobación
- Tener evidencia formal para trámites, seguimientos y constancias

> La fecha de aceptación del anteproyecto no depende únicamente de la fecha en que se descargó o consultó un documento; se conserva como un dato formal del proceso.

## 10. Documentos y entregables

En esta sección se gestionan los archivos relacionados con el proyecto.

### 10.1 Subir documentos
1. Accede al proyecto correspondiente.
2. Busca la sección de "Documentos" o "Entregables".
3. Selecciona la opción para cargar un archivo.
4. Elige el archivo desde tu equipo.
5. Verifica que el nombre y tipo del archivo sean correctos.
6. Guarda o sube el archivo.

### 10.2 Recomendaciones al subir archivos
- Usa nombres claros y descriptivos
- Verifica que el archivo corresponda al proyecto correcto
- Confirma que no esté vacío o dañado
- Comprueba que el formato sea el apropiado

## 11. Usuarios y permisos

El sistema distingue diferentes tipos de usuarios y permisos. Esto evita que una persona vea o edite información que no le corresponde.

Por ejemplo:
- Un estudiante puede consultar sus proyectos y su información personal.
- Un docente puede revisar proyectos o asesorar a estudiantes.
- Un administrador puede gestionar usuarios y cambios importantes del sistema.

Si un usuario intenta acceder a un proyecto o información no autorizada, el sistema puede bloquear la acción.

## 12. Cómo consultar tu información

Para revisar tu información:
1. Inicia sesión.
2. Dirígete a la sección correspondiente a tu perfil.
3. Consulta tus datos generales.
4. Si es necesario, actualiza la información correcta.

> Siempre verifica los datos antes de guardar, ya que la información personal y académica afecta el proceso del proyecto.

## 13. Buenas prácticas para usar el sistema

- Usa correos institucionales o válidos
- Guarda la contraseña en un lugar seguro
- Revisa los datos antes de enviar o guardar
- Mantén tus documentos actualizados
- Consulta el estado del proyecto con frecuencia
- Si no sabes qué significa un estado, pregunta al administrador o docente responsable

## 14. Solución de problemas

### 14.1 No puedo iniciar sesión
Revisa lo siguiente:
- Que el correo esté bien escrito
- Que la contraseña sea la correcta
- Que no exista un bloqueo temporal de la cuenta
- Que tu cuenta esté activa

### 14.2 No veo mis proyectos
Revisa si:
- Iniciaste sesión con el usuario correcto
- Tienes permisos para ver esa información
- El proyecto fue dado de alta correctamente
- El estado del proyecto no lo está ocultando por regla de negocio

### 14.3 El sistema tarda en cargar
Prueba lo siguiente:
- Recarga la página
- Verifica tu conexión a internet
- Intenta más tarde si hay problemas temporales
- Comunica el problema al administrador si persiste

### 14.4 No puedo subir un documento
Revisa:
- El formato del archivo
- El tamaño del archivo
- Que el proyecto al que se asocia sea el correcto
- Que el documento no esté dañado o vacío

## 15. Soporte

Si tienes dificultades con el sistema o necesitas ayuda, contacta al personal administrativo, docente o de soporte asignado.

En general, el soporte puede ayudarte con:
- Problemas de acceso
- Asignación de permisos
- Estados del proyecto
- Carga de documentos
- Error en datos o información

## 16. Resumen final

El sistema de vinculación de proyectos permite gestionar de forma ordenada y segura todo el proceso relacionado con la propuesta, revisión, seguimiento y cierre de proyectos de residencia o vinculación.

Gracias a sus funciones, los usuarios pueden:
- Registrarse y acceder de manera segura
- Crear y seguir proyectos
- Revisar estados e historial
- Subir documentos
- Mantener una organización continua del proceso académico

Este sistema facilita la comunicación entre estudiantes, docentes, asesores y administradores, y ayuda a mantener un control claro y formal de cada proyecto.

## 17. Contacto y cierre

Si necesitas una ayuda adicional, consulta con el administrador del sistema o con la persona encargada del proceso académico en tu institución.

Muchas gracias por usar el Sistema de Vinculación de Proyectos.
